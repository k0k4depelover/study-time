# study-time

## ⚡ FocusForge

> **"I just wanted to study, not configure a multi-tenant enterprise productivity workspace."**

A local-first, lightweight study session engine built with pure flow state (aka 100% vibecoded). It runs locally with a single command, keeps state in SQLite, and natively understands LLM agents via MCP and OpenAPI.

No Docker required. No cloud subscription. No 400MB `node_modules` just to track 45 minutes of calculus.

---

## ✨ Features

- 🏎️ **Single-command startup:** Zero setup friction. Run it, and it works.
- 💾 **SQLite persistence:** All your study sessions live in a clean, local `.db` file on your machine. Your data is yours.
- 🤖 **MCP-Ready (Model Context Protocol):** Designed from day one so Cursor, Claude, or any autonomous agent can generate and inject structured study routines directly into your session without scraping your DOM or burning tokens.
- 📝 **Markdown-first workflow:** Paste or inject structured tables with timing, checkpoints (25% / 50% / 75%), and subtask breakdowns.
- 🪶 **Vibecoded & Pragmatic:** Written to solve an immediate, real problem with minimal boilerplate and maximum execution speed.
